# Upwork Case Study

## Suggested Title
Code-First Unity Tower Defense Port With Maintainable Runtime Architecture

## Suggested Cover Image
Unity gameplay screenshot paired with a short caption about runtime bootstrap and code-first structure.

## Challenge
Port the same game space into Unity while avoiding an editor-only workflow that would make the project harder to review and maintain.

## Solution
I approached the Unity version with a code-first mindset, emphasizing runtime bootstrap, maintainable gameplay structure, and reviewable project organization instead of relying entirely on manually assembled scenes.

## Impact
This project proves Unity engineering depth, scalable runtime structure, and the ability to adapt an existing game concept to a different engine without copying the same architecture blindly.

## Why This Matters To Clients
It shows that I can deliver Unity projects that stay understandable over time, especially when gameplay systems and technical debt start to grow.
